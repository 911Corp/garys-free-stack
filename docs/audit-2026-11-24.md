## Security & dependencies
- `npm audit`: 9 issues (2 critical, 2 high) in the first lockfile, all from pinned older majors. Upgraded to React 19, React Router 7, Zod 4, Vite 8, Vitest 5, TypeScript 7 → **0 vulnerabilities**.
- No `innerHTML` / `dangerouslySetInnerHTML` / `eval`. Every external link: `rel="noopener"`.
- URL and JSON stack import: unknown ids, roles and flags are dropped (tested).
- No secrets, no backend, no cookies, no tracking. localStorage only, wrapped in try/catch.

## Functional (Playwright, 26 flows, all pass)
Idea → template → builder with inferred context · home search → explore · combinable filters and reset · favorites · compare dock and table · builder add/remove, missing-runtime warning, commercial GitHub Pages error, URL state · save → saved page · persistence after reload · JSON export → import · Markdown and CSV export · simulator over-quota pricing · API directory search · unknown resource page · mobile menu open/close · skip link.

Bugs found and fixed:
1. Builder state lagged behind clicks and typing (router transitions): local state now drives the UI, the URL mirrors it.
2. "import .json" was hidden on an empty builder.
3. Skip link navigated to a 404 route under hash routing.
4. Simulator showed Supabase 4 times when loaded from a template; Sentry errors were simulated with analytics events.
5. public-apis importer read only 20 APIs after an upstream format change: now header-aware, 2,493 APIs, sponsored tables skipped (test added).
6. Colour meaning on resource sheets: "card required: no" is now green, "account required: yes" red, neutral facts uncoloured.

## Accessibility (axe-core 4, WCAG 2 A/AA + best practices, 17 routes × desktop & mobile)
Initial: unlabeled selects (critical), heading order, missing h1, content outside landmarks. **Final: 0 violations.** Autofocus removed from Explore (mobile keyboard pop).
